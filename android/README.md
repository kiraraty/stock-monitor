# 哨灯 · Panel Android 0.14.0

原生 Kotlin 行情 App，Android 16+（API 36）。安装 [Panel-Android.apk](../dist/Panel-Android.apk)，可直接覆盖旧版并保留自选和外观设置。包名继续使用 `app.pnale.ticker`，以保持升级兼容；旧下载路径 `Pnale-Android.apk` 同步指向本次构建。

## 开始使用

1. 首页直接查看实时价格和最近 60 根 K 线。点击币种和 1m / 5m / 15m / 1h 切换；下方有自选列表。
2. 点「持续盯盘 → 开启」，允许通知后即可在后台接收行情、查看状态栏和下拉通知。普通通知模式无需悬浮窗权限。
3. 「设置 → 自选标的」输入 `ETH, BTC, XAU, CL, BZ`，停止输入后自动校验并应用；也可点「立即应用」。也支持中文逗号、换行、`BTCUSDT`、`ETH/USDT`；最多 30 个，默认 ETH / BTC。保存前查询当前合约目录并整体校验，无效输入不会覆盖原列表。
4. 「警报」配置独立规则；「外观」调整桌面行情牌、屏保、通知内容；「设置」管理通知、锁屏、悬浮和连接选项。

XAU 为黄金，CL 为 WTI 原油，BZ 为布伦特原油。它们显示的是币安 USDT 传统金融永续合约价格，并非直接来自 COMEX / NYMEX 的现货或交割期货报价。

## 自定义本地警报

最多保存 20 条规则，每条独立命名、新增、复制、删除、启用或停用：

- 标的：从当前已保存的自选中选择。
- 条件：短时急跌、短时急涨、跌破价格、突破价格。
- 急涨跌：自定义百分比和 1–60 分钟窗口；使用本机连续观察的窗口价格变化，不使用 24H 涨跌幅替代。
- 穿越价格：启动时若价格已经处于触发侧，需要先回到另一侧，再次穿越才触发。
- 日夜模式：默认按手机当地时间自动切换，22:00–08:00 铃声＋振动，白天仅振动。夜间起止可编辑，也可手动选“仅振动”或“铃声＋振动”；每条规则关闭的声音/振动仍保持关闭。试听也遵循当前模式。
- 提醒：10–120 秒，自选声音、振动；铃声可通过系统选择器更换。音量滑杆调整系统闹钟音量，App 不会强行调到最大。
- 默认只触发一次，触发前持久化停用状态；也可设置冷却后重复，冷却为 1–1440 分钟。冷却结束后重新采集观察窗口。
- 「试听当前设置 10 秒」可检查声音与振动；通知和警报页面都有「停止响铃」，到时自动停止。

规则改动自动保存，输入未完成时保留草稿。默认没有启用任何规则；点「启用当前规则」才开始监测并启动后台盯盘；停止盯盘后暂停监测，再次启动将重新积累窗口。超过 15 秒的旧报价、无效/未来时间、断线或样本间隔超过 20 秒都不能形成连续窗口。删除自选中的标的后，该标的规则会等待行情；应同时调整或停用对应规则。

手机本地规则读取 App 的币安行情。服务端使用成交流进行更细的异常和插针检测；**服务器事件尚未推送到手机**，手机也还不能编辑服务器配置。

## 展示与外观

- 通知、可选浮窗和页面共享行情连接。通知约每 5 秒更新；下拉可切换币种或停止盯盘。状态栏可显示动态数字或普通图标，空间与样式受系统限制。
- 小悬浮条可拖动，`↗` 展开 K 线，`−` 收起，`×` 隐藏窗口并保留通知。大小 65%–125%（默认 80%），不透明度 35%–100%（默认 80%），立即生效并保存。
- 界面字体支持标准、纤细、等宽、衬线，界面字号为 90% / 100% / 110% / 120%；页面、按钮和输入框统一生效。
- 顶部文字独立设置标准/纤细/粗体/等宽/衬线、10–26 sp、预设颜色或任意 `#RRGGBB` 颜色、24H 涨跌配色与阴影。可在“外观 → 顶部 / 状态栏文字”实时预览。点选固定颜色会同时关闭“颜色跟随 24h 涨跌”，断线用 `!` / `—` 标记而不改写颜色；HTTP 新鲜快照使用 `~价格`。数字通知图标共用字体，但颜色与尺寸由系统统一控制；流体云文字也由系统排版。
- 顶部纯价格模式保持透明；系统手势拦截拖动时，可从设置中的位置滑杆调整。锁屏、安全页面或系统权限页面可能隐藏它。
- 锁屏行情可开关；实时活动 / 流体云可请求系统提升。App 区分已请求和系统实际提升；用户已反馈旧版在其 ColorOS 可显示，但新版最终胶囊排列仍需同一真机核对。
- 桌面行情牌和系统充电屏保支持单币、上下双币、左右并排、四宫格。屏保使用 DreamService；属于亮屏显示，并非原生息屏 AOD。
- 玻璃、极简黑底、终端、普通卡片；四种配色、标准/纤细/粗体/等宽/衬线字体、字号 75%–135%、名称/涨跌开关、亮度 10%–100%。玻璃为绘制渐变与高光，不包含系统背景的实时折射。
- 胶囊内容可选币种+价格、币种+涨跌、价格+涨跌、图标+价格，默认避免两侧重复价格；小数精度和通知展示数量可调。系统胶囊材质、圆角、宽度与字号仍由 ColorOS 控制。

## 自动保存与备份

所有显示选项、字体、颜色、位置、盯盘开关和显示模式自动保存，按钮与开关从实际已存值刷新。自选经过真实合约目录校验才生效；警报有效编辑自动保存且保留原启用状态，未填完的输入保留草稿。

「设置 → 配置与自动备份」显示最近自动备份时间，并支持恢复上一个完整快照、导出 JSON 和导入 JSON。备份有版本与类型校验，先校验整份文件再恢复，错误文件不会覆盖当前配置；写入采用原子文件和恢复日志。自动备份保存在 App 私有目录，卸载/清除数据会删除；换机或卸载前请导出。备份不包含系统授权、系统音量或服务器密钥。

开启盯盘后，后台服务与显示模式会记住；系统回收后请求恢复，重新打开 App 也会恢复。主动点停止会持久保存关闭状态。可选「重启手机后恢复盯盘」，默认关闭；需先正常开启盯盘和授予通知权限。外观与自选配置不依赖服务运行。

## 0.14.0 更新

- 首页切换币种或 K 线周期不再中断行情：先用 HTTP 取新图表，再开新推送连接，旧连接继续推送所有币的报价，直到新连接收到数据才关闭。顶部 / 状态栏价格全程保持实时。
- 行情卡片底部显示实际提供数据的交易所（Gate / Binance / Binance · 中继 / HTX），不再固定写 Binance。

## 0.13.0 更新

- 行情来源新增「自动（推荐，默认）」和 HTX：自动模式优先 Gate（国内通常可直连），连续失败改用币安（经新加坡中继），再改用 HTX（api.hbdm.vn，按 HTTP 每 3 秒轮询），并记住上次可用的来源。
- 修复国内网络拉不到行情：国内出境链路对大响应限速（实测约 20 KB/s），原先自选超过 5 个时一次拉取全部合约行情（约 480 KB）、校验自选时拉取完整合约列表（约 450–650 KB），都会超时。现在一律按币种并行请求（每个约 0.5–1.5 KB），实测冷启动到实时推送从 59 秒降到 9–12 秒。

## 0.12.0 更新

- 顶部 / 状态栏币种不再限制数量：超过「顶部每屏显示」（1–6 个，默认 3）时按页轮播，间隔 3–10 秒可选；窗口宽度按最宽一页固定，不随翻页跳动。「每币一个」状态栏图标仍最多 6 个。
- 自动线路记住上次可用的线路：国内网络下不再每次重连、切币都先等币安直连超时。

## 0.11.0 更新

- 警报页改版：首页一眼看到所有规则（一句话描述、实时状态、开关直接启停），点规则进入独立编辑页；标的、条件、观察窗口、提醒时长和冷却都改为点选，顶部实时显示「这条规则会…」。
- 规则可「从服务器恢复」，也可在警报页直接进入「配置与备份」；规则仍随本机自动备份。
- 顶部 / 状态栏多币上限从 4 个提高到 6 个。

## 0.10.0 更新

- 警报可改由服务器监测：「警报 → 服务器监测」填入访问令牌并开启，规则修改后自动同步到新加坡服务器；服务器按币安逐笔成交判断，手机每约 5 秒拉取触发结果并在本机按日夜时段响铃。手机需保持盯盘开启；超过 2 分钟才收到的警报只记录不补响。关闭开关即回到手机本地监测。

## 0.9.0 更新

- 顶部纯价格和状态栏图标可同时显示多个币（设置 → 悬浮与顶部文字 → 顶部 / 状态栏币种，最多 4 个）；状态栏图标选「每币一个」时，额外币种各发一条静默通知。
- 行情来源可切换：币安（默认，保留直连 / 新加坡中继）或 Gate（国内网络通常免代理直连）。Gate 价格为其自身永续成交价，与币安略有差异。

## 连接与运行边界

行情来自 Binance U 本位 USDT 永续公开 REST / WebSocket，无账户、交易或资金功能。最新成交价和 24H 统计来自 `@ticker`，图表来自 `@kline_<interval>`。首次和重连获取报价及 60 根 K 线；图表含当前未收盘 K 线，缺口会回填。行情过期与 K 线待更新分别展示。

「设置 → 行情连接」可选择自动切换、币安直连、新加坡中继。自动优先直连，REST 不可用或 WS 连续失败会转向用户的新加坡服务器；中继只转发公开币安行情，TLS 校验限定到该服务器证书，不需要手机配置代理。WS 不通时可每约 5 秒请求 HTTP 快照，界面明确标为兜底；HTTP 期间暂停价格警报，恢复 WS 后重建连续窗口。原始交易所时间不被中继或客户端改写。网络断开立即标记，网络恢复自动重连。具体运营商是否能到达中继仍取决于实际网络。

提供系统电池优化和应用后台权限入口；ColorOS 还可允许后台活动 / 自启动、锁定最近任务。App 不强行更改系统电池策略，不使用无限唤醒锁。只有响铃期间使用有时限的唤醒锁；持续监测受 Android / ColorOS 的后台联网与省电策略影响。全屏警报取决于系统的全屏通知许可；尚未在 OPPO 真机独立验证音量、勿扰、锁屏唤醒或长时间熄屏持续联网。可先用十秒试听确认设备实际表现。APK 内没有测试代理配置。

这是一份本地 debug 签名安装包。实测截图、自动化结果和版本边界见 [VALIDATION.md](VALIDATION.md)；ColorOS 官方接口调查见 [OPPO_API.md](OPPO_API.md)。

## 构建与验证

JDK 17、Android SDK 36 / Build Tools 36.0.0，Gradle 9.3.1、AGP 9.1.0、OkHttp 4.12.0。

```sh
# 仓库根目录
zsh scripts/build-android.sh

# Android 子目录
./gradlew :app:testDebugUnitTest :app:lintDebug --console=plain --max-workers=1
```

`MainActivity` 为首页，`MarketSettingsActivity` 管理显示和连接，`StyleActivity` 管理外观，`AlarmSettingsActivity` 管理规则。`AlarmDelivery.kt` 处理手机本地日夜时段，`Typography.kt` / `SettingsUi.kt` 统一界面字体与卡片控件，`TopPriceStyle.kt` 应用顶部文字样式。`PriceAlarm.kt` 包含规则与窗口状态机，`AlarmController` 管理音频/振动/限时释放，`OverlayService` 负责后台行情、规则触发和通知。`MarketEngine` 负责共享连接、快照、WS 与重连。

`ConfigStore.kt` / `ConfigCodec.kt` 管理自动快照、备份校验与恢复，`BackgroundTracking.kt` 管理开关/开机恢复，`MarketTransport.kt` 为直连和专用 TLS 中继建立独立客户端。中继部署与证书维护见 [relay/README.md](../server/relay/README.md)。
